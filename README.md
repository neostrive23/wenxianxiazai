# 文献搜索下载工具

一个无需安装、打开网页即可使用的文献检索小工具，面向需要快速查找论文、确认开放获取状态和定位全文入口的用户。

在线地址：<https://neostrive23.github.io/wenxianxiazai/>

## 功能

- 同时检索 Crossref、OpenAlex、Europe PMC 三个学术数据库
- 自动合并不同数据库返回的重复论文
- 支持年份、期刊、被引数和近似 IF 筛选
- 支持按相关度、最新发表、被引数和近似 IF 排序
- 可选择是否显示摘要
- 开放获取论文提供 PDF 入口
- 付费墙论文提供 Sci-Hub 尝试入口和 DOI 原文入口
- 提供问题与建议反馈入口

## 使用方法

1. 输入英文关键词、论文标题或 DOI。
2. 点击“搜索”。三个数据库会自动并行查询。
3. 根据需要设置年份、期刊、被引数、近似 IF 和开放获取筛选。
4. 使用排序选项调整结果顺序。
5. 需要查看摘要时，勾选“显示摘要”。

英文关键词通常比中文关键词获得更稳定的结果，例如：

```text
single-cell RNA-seq
spatial transcriptomics
rice disease resistance
```

## 去重规则

- 优先按照规范化 DOI 去重；
- 没有 DOI 时，按照标题特征进行匹配；
- 重复记录会尽量合并作者、摘要、PDF、日期和引用数等信息；
- 预印本与正式发表版本可能因 DOI 或年份不同而分别保留。

“每源 15 条”表示每个数据库最多返回 15 条，去重后不保证仍有 30 条结果。

## 数据说明

- Crossref：出版社 DOI 和文献元数据覆盖广；
- OpenAlex：综合型学术数据库，提供开放获取位置和引用数据；
- Europe PMC：生命科学、医学方向覆盖更有优势，并提供部分全文链接。

页面中的“IF≈”是 OpenAlex 两年篇均被引指标，仅作参考，不等同于 Clarivate JCR 官方影响因子。最新 JCR 影响因子需要授权数据服务。

## 反馈

点击页面底部的“问题 / 建议反馈”，填写内容后提交。首次使用在线反馈时，维护者邮箱可能需要先完成一次验证；如果本地直接打开 HTML 文件，反馈会转为邮件客户端发送。

## 使用统计

网页接入 Google Analytics 4，用于统计页面访问、搜索次数和反馈提交次数，不上传具体搜索关键词。统计数据可在 Google Analytics 中查看。

## 注意事项

- 本工具为纯前端页面，不保存检索历史；
- 数据库接口可能受到网络环境、跨域策略和公共限流影响；
- PDF 是否能下载取决于论文的开放获取状态；
- 使用全文入口时，请遵守所在地法律法规及版权规定。

## 技术说明

项目为单文件静态网页，入口文件为 `index.html`，可直接通过 GitHub Pages 发布。
